# TG Networking

Website: `/tg-networking`; private member dashboard: `/tg-networking/account`.

The Next.js API validates trade applications, uses scrypt password hashes and hashed 12-hour sessions, checks Origin on writes and rate limits account actions. Registration returns a single-use recovery code. There is no email verification or email password-reset service: owner business/contact checks precede approval. Do not claim self-registration verifies identity.

The Worker accepts only server-authenticated requests. API_KEY is a private database bridge credential; CRM_KEY is separately restricted to CRM operations. Neither belongs in client code or Git. Vercel has the backend URL, sensitive API key and canonical site origin. `.env*` stays ignored. No changes to DNS or existing website hosting provider.

Accounts and inventory start pending review. Optional network consent is distinct from enquiry consent. Changing trade profile information resets review; withdrawing network consent alone preserves supplier approval. Approval is not credit or stock assurance. Public inventory responses contain only opaque listing ID, product, quantity, condition, city, country and upload date. No supplier identity, SKU, email, cost, original CSV or private CRM data is returned to other members. Every enquiry routes to Toronto Gadgets.

CSV: maximum 500 KB and 500 product rows; exact template headings; no formulas, duplicate SKUs or embedded product contacts. New uploads replace prior active uploads atomically and need review. Current member view returns the latest 500 approved, shared listings from approved consenting network suppliers. Availability expires after 30 days based on upload time, even if a scheduled job is late. Price and stock require independent confirmation before quoting. Owner must check product and location fields for identity leakage before publication.

A refreshed upload restarts the clock; replaced files do not generate reminders. Inventory removal is automatic even while reminders are off. No invitation emails are sent by this code.
